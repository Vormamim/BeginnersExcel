📘 What is a Spreadsheet?

A spreadsheet is a digital table made of rows and columns. It helps you organize information, calculate answers, and create charts.

You can use spreadsheets to track scores, plan budgets, compare data, and build useful school projects.

🖥️ Open Excel

Open Microsoft Excel on your computer.
Choose Blank workbook.
Wait for the spreadsheet screen to load.
Tip

If Excel is not available, you can still follow the lesson using Google Sheets or another spreadsheet app with similar tools.

🔍 Parts of the Screen

Part What it does
RowRuns across the page and is numbered.
ColumnRuns up and down the page and uses letters.
CellA single box where you type data.
Formula BarShows what is inside the selected cell.
Sheet TabLets you switch between different sheets.

💾 Save Your Workbook

Click File → Save As.
Choose a folder you can find again later.
Name the file something clear like lesson1-practice.xlsx.
Click Save.
