Lesson 6: Sorting & Filtering

Learn how to put data in order and show only the rows you need so big tables become easier to read.

Start Lesson

🎯 Learning Goals

Sort words from A to Z and Z to A
Sort numbers from biggest to smallest or smallest to biggest
Turn on filters to hide rows you do not need
Use text filters and number filters to find information quickly

🔍 Step 1: Why Sort and Filter?

Sorting puts data in order. Filtering hides rows that do not match what you want to see.

Sorting helps you find the biggest, smallest, first, or last items.
Filtering helps you focus on only the rows you care about.
These tools are very useful when a table has lots of rows.

🔤 Step 3: Sort Names A to Z

Now sort the table by student name.

Click any cell in the Student Name column.
Click the Data tab.
Choose Sort A to Z.
Watch the whole table move into alphabetical order.
Good to know

When you sort one column, the other columns move too so each row stays together.

🔡 Step 4: Sort Names Z to A

Try the reverse order too.

Click any cell in the Student Name column again.
Choose Sort Z to A.
The names near the end of the alphabet should move to the top.

🔢 Step 5: Sort Numbers

You can sort scores too.

Click any cell in the Math column.
Choose Sort Largest to Smallest.
The student with the highest Math score should move to the top.
Try sorting the PE column from Smallest to Largest too.

🧰 Step 7: Turn On Filters

Filters add little dropdown arrows to the top row.

Go back to your school grades table.
Click any cell inside the table.
Click Data → Filter.
Small dropdown arrows should appear in the heading row.

🎯 Step 8: Use a Number Filter

Number filters help you show only rows with scores above or below a certain value.

Click the filter arrow in the Math column.
Choose a number filter like Greater Than or Equal To.
Type 90.
Click OK.
Now only students with Math scores of 90 or more should be visible.

📝 Step 9: Use a Text Filter

You can filter words too.

Use the movie table or another table with words.
Turn on filters if they are not already on.
Click the filter arrow in the Genre column.
Uncheck Select All.
Check only one genre, like Comedy or Animation.
Click OK.
