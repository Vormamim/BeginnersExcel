Lesson 7: IF Statements

Learn how to make Excel show different results depending on what your data says.

Start Lesson

🤔 Step 1: What is an IF Statement?

An IF statement checks something and gives one answer if it is true and a different answer if it is false.

Think of it like this

If it is raining, take an umbrella. Otherwise, wear sunglasses.

In Excel, the formula looks like this:

=IF(condition, value_if_true, value_if_false)
Condition = what Excel checks
Value if true = what to show if the condition is met
Value if false = what to show if the condition is not met

🧮 Step 2: Type Your First IF Table

Start with this simple student score table.

Student Score Result
Alex72
Blake45
Casey91
Dana38
Evan55
Type the headings in cells A1 to C1.
Type the student names and scores underneath.
Leave the Result column empty for now.

✍️ Step 3: Write Your First IF Formula

Now tell Excel to show Pass if the score is 50 or more, or Fail if it is below 50.

Click cell C2.
Type this formula:
=IF(B2>=50,"Pass","Fail")
Press Enter.
C2 should now show Pass.
Formula breakdown

B2>=50 checks the score. "Pass" appears if true. "Fail" appears if false.

🖱️ Step 4: Copy the Formula Down

You do not have to type the formula again and again.

Click cell C2.
Move to the bottom-right corner of the cell until you see the small +.
Drag down to C6.
Excel fills the formula into the other rows.
Alex → Pass
Blake → Fail
Casey → Pass
Dana → Fail
Evan → Pass

🔢 Step 5: IF with Numbers

IF formulas can return numbers too, not just words.

Add a new heading called Bonus in D1.
In D2, type:
=IF(B2>80,10,0)
Press Enter.
Copy the formula down to the other rows.

This gives 10 if the score is above 80, and 0 if it is not.

⚖️ Step 6: Comparison Symbols

These symbols help IF formulas compare values.

Symbol Meaning Example
>Greater thanB2>80
<Less thanB2<50
>=Greater than or equal toB2>=50
<=Less than or equal toB2<=100
=Equal toB2=100
<>Not equal toB2<>0

🎓 Step 7: Use Nested IF for Letter Grades

You can put one IF inside another IF to create more than two results.

=IF(B2>=90,"A",IF(B2>=80,"B",IF(B2>=70,"C","D")))
90 or more = A
80 or more = B
70 or more = C
Anything else = D
Why use nested IF?

It lets Excel choose from more than just two answers.

🍬 Step 8: Try IF with Candy Data

You can use IF in other kinds of tables too.

Open candy_data.csv.
Find the Teeth Danger column.
Add a new heading called Dentist Warning.
Use a formula like this:
=IF(H2>=4,"⚠️ Be Careful!","😊 OK")

If the danger number is 4 or higher, Excel shows a warning.

🧠 Step 9: Try the IFS Function

If you have a newer version of Excel, you can use IFS for lots of conditions.

=IFS(B2>=90,"A", B2>=80,"B", B2>=70,"C", B2>=60,"D", B2<60,"F")

This works like a tidy version of multiple IF statements.

🔍 Step 10: COUNTIF Review

COUNTIF counts how many cells match a rule.

=COUNTIF(B2:B11,">=90")
=COUNTIF(C2:C11,"Pass")
The first formula counts scores of 90 or more.
The second formula counts how many cells say Pass.
