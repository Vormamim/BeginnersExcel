Lesson 4: Charts & Graphs

Learn how to turn your table into a chart so your data is easier to read, compare, and understand.

Start Lesson

🎯 Learning Goals

Understand why charts are useful
Create a simple chart from data in a table
Add a chart title and data labels
Know when to use bar, pie, and line charts

🧪 Lesson Activity

Look at the demo sheet first. Then type the tables below into Excel or Google Sheets and turn them into charts.

Open the demo sheet and look at the different chart tabs.
Open a blank workbook in Excel or a blank Google Sheet.
Type the Bar Chart table into your spreadsheet.
Select the whole table, including the headings, and insert a chart.
Add a clear title and turn on data labels.
Next, type the Pie Chart table and create a pie chart.
After that, type the Line Chart table and create a line chart.
Compare the charts and decide which one is easiest to read.
Save your file with a clear name.

How to use this

First, study the demo sheet. Then open a blank spreadsheet, type the same tables yourself, and create matching charts.

📊 Step 1: Why Use a Chart?

A chart turns a table of numbers into a picture. This makes the information easier to understand quickly.

Charts help you compare values.
Charts make patterns easier to spot.
Charts can make your work more interesting to look at.
Example

It is easier to see who has the highest score by looking at a chart than by reading lots of numbers in a table.

🧮 Step 2: Type the Bar Chart Table

Start with a simple table about game scores.

Player Score
Alex150
Blake230
Casey175
Dana310
Evan190
Type Player in cell A1.
Type Score in cell B1.
Type the names and scores underneath.

🖱️ Step 3: Select the Bar Chart Data

The spreadsheet needs to know which data you want to turn into a chart.

Click cell A1.
Hold Shift.
Click cell B6.
Now the range A1:B6 should be selected.
Important

Make sure you include the headings as well as the numbers. The headings help label the chart correctly.

📈 Step 4: Insert a Bar Chart

Now you can turn the selected data into a chart.

Click the Insert menu or tab.
Choose Chart.
If there is a choice, pick a Bar Chart or Column Chart.
Your spreadsheet should create a chart from the table.
Do not worry if it looks different

Excel and Google Sheets do not always look exactly the same, but the steps are very similar.

🏷️ Step 5: Add a Title and Data Labels

A title tells the reader what the chart is about. Data labels show the exact number on each bar or column.

Click the chart title area.
Type Game Scores Comparison.
Click the chart once and look for an option called Data Labels.
Turn data labels on.

🎨 Step 8: Change the Style

You can make your chart easier to read and more fun to look at.

Click the chart.
Try changing the color.
Make the chart bigger or smaller if needed.
Move it so it does not cover your table.

📚 Step 9: Know the Main Chart Types

Different charts are useful for different kinds of data.

Chart type Best for
Bar ChartComparing different items
Column ChartComparing values in vertical bars
Line ChartShowing change over time
Pie ChartShowing parts of a whole
