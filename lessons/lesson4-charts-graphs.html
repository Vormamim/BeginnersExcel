Lesson 4: Charts & Graphs

Learn how to turn your table into a chart so your data is easier to read, compare, and understand.

Start Lesson

🎯 Learning Goals

Understand why charts are useful
Create a simple chart from data in a table
Add a chart title and data labels
Know when to use bar, pie, and line charts

🧪 Lesson Activity

Look at the demo sheet first. Then make your own chart by following the steps below.

Open the demo sheet and look at the table and the chart.
Open a blank workbook in Excel or a blank Google Sheet.
Type a small table with names and scores.
Select the whole table, including the headings.
Insert a chart.
Choose a chart type that matches your data.
Add a clear title.
Add data labels so the numbers are easy to see.
Save your file with a clear name.

How to use this

First, study the demo sheet. Then open a blank spreadsheet, type your own table, and create a chart from it.

📊 Step 1: Why Use a Chart?

A chart turns a table of numbers into a picture. This makes the information easier to understand quickly.

Charts help you compare values.
Charts make patterns easier to spot.
Charts can make your work more interesting to look at.
Example

It is easier to see who has the highest score by looking at a chart than by reading lots of numbers in a table.

🧮 Step 2: Type a Simple Table

Before you can make a chart, you need some data.

Click cell A1 and type Player.
Click cell B1 and type Score.
In A2, type Alex. In B2, type 150.
In A3, type Blake. In B3, type 230.
In A4, type Casey. In B4, type 175.
In A5, type Dana. In B5, type 310.
In A6, type Evan. In B6, type 190.

🖱️ Step 3: Select the Data

The spreadsheet needs to know which data you want to turn into a chart.

Click cell A1.
Hold Shift.
Click cell B6.
Now the range A1:B6 should be selected.
Important

Make sure you include the headings as well as the numbers. The headings help label the chart correctly.

📈 Step 4: Insert a Chart

Now you can turn the selected data into a chart.

Click the Insert menu or tab.
Choose Chart.
If there is a choice, pick a Bar Chart or Column Chart.
Your spreadsheet should create a chart from the table.
Do not worry if it looks different

Excel and Google Sheets do not always look exactly the same, but the steps are very similar.

🏷️ Step 5: Add a Chart Title

A title tells the reader what the chart is about.

Click the chart title area.
Type Game Scores Comparison.
Click away from the chart when you are done.

🔢 Step 6: Add Data Labels

Data labels show the exact number on each bar or column.

Click the chart once.
Look for an option called Data Labels.
Turn data labels on.
Now the numbers should appear on the chart.

🎨 Step 7: Change the Style

You can make your chart easier to read and more fun to look at.

Click the chart.
Try changing the color.
Make the chart bigger or smaller if needed.
Move it so it does not cover your table.

📚 Step 8: Know the Main Chart Types

Different charts are useful for different kinds of data.

Chart type Best for
Bar ChartComparing different items
Column ChartComparing values in vertical bars
Line ChartShowing change over time
Pie ChartShowing parts of a whole

🧪 Try It: Make a Different Chart

Use the same table again.
Try changing your chart to a different type.
Look at how the information changes when you use a bar chart, column chart, or pie chart.
Decide which chart is easiest to read.

💾 Step 9: Save Your Workbook

Click File.
Click Save As.
Choose a folder you can find again later.
Name the file something clear like lesson4-charts-graphs.xlsx.
Click Save.
