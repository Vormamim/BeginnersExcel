## 🚀 How to Use This Tutorial

1. **Read each lesson** in order — they build on each other.
2. **Try the activities** at the end of every lesson.
3. **Use the data files** to practice your skills.
4. **Complete the Minecraft task** when you're ready for a bigger challenge.
5. Have fun and don't be afraid to experiment! 🎮

## 💡 What is Excel?

Excel is a **spreadsheet program** made by Microsoft. People use it every day to:

- 📊 Track scores and grades
- 💰 Manage money and budgets
- 📈 Create charts and graphs
- 📋 Organize lists and data

Whether you want to track gaming scores, plan a party, or organize sports team stats — spreadsheets can do it all!
